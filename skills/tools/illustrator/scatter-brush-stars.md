# 散布ブラシで星空を作成する

## 概要
Illustratorの散布ブラシ機能を使い、ランダムな大きさ・配置の星を効率的に描画する手法。

## 操作手順

### 1. 星の元オブジェクトを作成
1. 楕円形ツール（L）で正円を作成（例: 10mm × 10mm）
2. 塗り: 黒、線: なし

### 2. 散布ブラシに登録
1. 正円を選択 → ブラシパネル（ウィンドウ > ブラシ / Window > Brushes）
2. パネルメニュー → 新規ブラシ → 「散布ブラシ（Scatter Brush）」→ OK
3. 散布ブラシオプション:
   - **サイズ（Size）**: ランダム、5% 〜 10%
   - **間隔（Spacing）**: 固定、10%
   - **散布（Scatter）**: ランダム、-500% 〜 500%
   - **方式（Colorization Method）**: 彩色（Tints）
4. OK → 元の正円は削除

### 3. 星を描画
1. ブラシツール（B）を選択
2. ブラシパネルで登録した散布ブラシを選択
3. 線: 白、塗り: 白
4. アートボード上にランダムに線を引く（3本程度）
5. 奥行き表現: 一部の線を選択して不透明度を30%に（透明パネル）

### 4. pixi.js用アセット書き出し時の注意
- **オブジェクト > アピアランスを分割（Object > Expand Appearance）** で個別オブジェクトに変換
- SVGまたはPNG（透過）で書き出し

## 散布ブラシオプション詳細
| パラメータ | 意味 | 星向け推奨値 |
|-----------|------|-------------|
| サイズ | 各オブジェクトの大きさ | ランダム 5%〜10% |
| 間隔 | オブジェクト間の距離 | 固定 10% |
| 散布 | パスからの垂直方向のばらつき | ランダム -500%〜500% |
| 回転 | 各オブジェクトの角度 | 円なので不要 |
| 方式 | 色の適用方法 | 彩色（線の色で着色） |
