# 発光トレイル／オーラの多層構築

2Dアニメ風の「半透明オーラの尾」を Photoshop で組む際の層構造と合成モードの定石。
流星・魔法の軌跡・エネルギー波など、芯のある発光帯に共通して使える。

## 基本構造：芯 ＋ 同形状グローの2枚1組

1. **芯レイヤー**: ベクターや硬いブラシで帯を描く。光源（頭部）側を太く、遠いほど細くテーパーさせる
2. **グローレイヤー**: 芯を複製し、ぼかして合成モードを発光系に変える
3. 帯を複数本（芯・中間・外側）に分ける場合は、この2枚組を本数分作る

出典: Clip Studio Tips「Magical Light Trail Effect」(https://tips.clip-studio.com/en-us/articles/4549)

## 層ごとの合成モードの使い分け

| 層 | 合成モード（日本語 / English） | 役割 |
|----|------|------|
| 内側の核 | 加算（発光） / Linear Dodge (Add) | 最高輝度。狭く強い光 |
| 中間 | 覆い焼きカラー / Color Dodge | 彩度とコントラストを足す |
| 外側の広がり | スクリーン / Screen | ぼんやりした拡散。広く弱い光 |
| 下地の色を活かしたい場合 | 覆い焼き（発光） / Color Dodge 系 | 加算より控えめ |

光が飛びすぎて白くなる場合はレイヤー不透明度を 60〜80% に落とす。

出典: manga.jpn.org「オーラエフェクト作り方をレイヤー別に徹底解説」

## 内→外への色シフト

- 内側ほど明るく、外側ほど暗く・色相をずらす
- 神秘系: 白 → 淡い青 → 緑 → ラベンダー
- 炎系: 白／黄 → オレンジ → 赤
- 背景はオーラと同系統の極端に暗い色にすると浮き上がる
- 配色比率の目安: メイン 70% / サブ 25% / アクセント 5%

## Photoshop 操作手順（動画より）

出典: YouTube「How to Create light Trails Effect in Photoshop - Glow Effect」(https://www.youtube.com/watch?v=3SrvuDtP7nA)

1. 新規レイヤーにペンツール（Pen / P）でパスを引き、パスパネル右クリック →「パスの境界線を描く（Stroke Path）」。ツール: ブラシ、筆圧シミュレートはオフ。硬さ 100% の円ブラシで芯を作る
2. 芯レイヤーを右クリック →「スマートオブジェクトに変換（Convert to Smart Object）」。後からぼかし量を調整可能にするため
3. フィルター → ぼかし → パスぼかし（Filter > Blur Gallery > Path Blur）で流れの方向にぼかす。目安: 速度 195%、テーパー 9%
4. 芯レイヤーを「リニア覆い焼き（加算）（Linear Dodge (Add)）」に
5. Cmd+J で複製 →「覆い焼きカラー（Color Dodge）」に
6. さらに Cmd+J で複製 →「スクリーン（Screen）」にし、フィルター → ぼかし → ガウスぼかし（Gaussian Blur）半径 90px 程度で大きく広げる
7. 全レイヤーを Cmd+G でグループ化し、グループにレイヤーマスクを追加。硬さ 0% の黒ブラシで末端を塗って減衰（フェードアウト）させる

## 流星トレイルへの適用メモ

- Illustrator 側では「芯は短く太め、外側ほど長く細く」の形の差だけ作っておけばよい。色とぼかしは Photoshop で層ごとに決める
- 減衰は「頭部側は濃く、末端は透明」。グループマスクに黒→白のグラデーションを引くのが最も安定する
- 外側の層ほどガウスぼかしを強く、色相を暗い方へずらす
- 芯のエッジは残したいので、芯レイヤー本体にはガウスぼかしをかけず、複製側だけぼかす
