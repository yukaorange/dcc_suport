# Illustrator 散布ブラシでパーティクル表現

出典: [粒子状イラストはこう作る！｜イラレチュートリアル](https://www.youtube.com/watch?v=oxYk5epsp2c)

## 散布ブラシの作成手順

### 1. 粒子の元となる円を作成
- 楕円形ツール (L) でクリック → 高さ10mm × 幅10mm の正円
- 塗り: 黒、線: なし

### 2. 散布ブラシとして登録
1. 正円を選択
2. ブラシパネル → 右上メニュー → **新規ブラシ** → **散布ブラシ** → OK
3. オプション設定:
   - **サイズ**: ランダム / 1% 〜 10%（小さな粒子が大小ランダムに）
   - **間隔**: 固定 / 5%
   - **散布**: ランダム / -10% 〜 10%（パスからの距離のばらつき）
   - **回転**: そのまま（円なので影響なし）
   - **着色**: **彩色**（後から色変更可能にする重要設定）
4. OK → 元の正円は削除してよい

### 3. パスに適用
- ペンツールや鉛筆ツールで弧状のパスを描く
- パスを選択 → ブラシパネルから散布ブラシをクリック
- パスに沿って粒子が散布される

### 4. 広がりのバリエーション（追従パーティクル）
1. ブラシパネルで散布ブラシを**複製**（ドラッグ＆ドロップで新規アイコンに重ねる）
2. 複製をダブルクリック → **散布を -100% 〜 100%** に変更
3. ブラシツール (B) で軌道の周囲に自由に描画 → 粒子が広範囲に散る

## ショートカット
- 楕円形ツール: L
- ブラシツール: B

## 応用: パーティクル軌跡への活用
- ペンツール (P) で弧状パスを描く → 散布ブラシ適用で光の軌跡表現
- 散布の範囲を狭め（-10%〜10%）にするとパスに沿った密な軌跡に
- 散布の範囲を広げ（-100%〜100%）にすると拡散する粒子に
- 着色を「彩色」にしておけば、線の色を変えるだけで粒子の色が変わる
