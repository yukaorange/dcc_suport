# スクロールリボン（巻物風シェイプ）の作り方

出典: [スクロールリボンのつくりかた｜本日のイラレ](https://www.youtube.com/watch?v=A5W_pHxv8bw)

## 概要
スパイラルツール → パス連結 → リフレクトコピー → ライブペイント → ワープ効果 の流れで巻物風リボンを作成する。

## 手順

### 1. スパイラルの描画
- ツールパネル「直線ツール」長押し →「**スパイラルツール**」
- ドラッグ中に **↑/↓キー** で巻き数を調整（1.5回転がおすすめ）
- **Shift** を押しながらドラッグ終了で正方形バウンディングボックスに整列

### 2. 垂直線の追加
- **直線ツール** でスパイラルの左端・右端・中央に垂直線を3本描画

### 3. パスの連結
- スパイラルと中央の垂直線を選択
- **オブジェクト（Object）→ パス（Path）→ 連結（Join）**（⌘J）

### 4. 高さ調整
- バウンディングボックスの上下ハンドルをドラッグして好みの高さに

### 5. 曲線の一部を複製
- **ダイレクト選択ツール（A）** で右側終点付近のアンカーポイントを選択
- コピー（⌘C）→ 前面ペースト（⌘F）→ 上方にドラッグ

### 6. 直線パスの延長
- **ペンツール（P）** で複製した曲線の左右終点から下方に垂直線を伸ばす

### 7. リフレクトコピー（左右対称化）
- 全体を選択 → **リフレクトツール（O）**
- 右側に基準点をクリック
- **Shift+Option(Alt)** を押しながらドラッグで反転コピー

### 8. パスの再連結
- 上部の水平曲線同士を選択 → ⌘J で連結
- 左右のスパイラルもそれぞれ ⌘J で連結

### 9. ライブペイントで塗りつぶし
- 全選択 →「シェイプ形成ツール」長押し →「**ライブペイントツール（K）**」
- 塗り色を選んでリボン中央部・巻物内側をクリックして塗りつぶし

### 10. ワープ効果で湾曲
- 全選択 → **効果（Effect）→ ワープ（Warp）→ 円弧（Arc）**
- 方向: 水平 / カーブ: 約 -28%（プレビューで確認しながら調整）

## ショートカット
| キー | 機能 |
|------|------|
| ⌘J | パス連結 |
| ⌘C / ⌘F | コピー / 前面ペースト |
| A | ダイレクト選択ツール |
| P | ペンツール |
| O | リフレクトツール |
| K | ライブペイントツール |
| Shift+Opt | リフレクトで反転コピー |

## ポイント
- スパイラルの巻き数でくるっと感を調整
- リフレクトツール+Optionで左右対称を一発作成
- ワープ効果は非破壊なので後からカーブ量を再調整可能
