# Photoshop フォグ（霧）の作成テクニック — べた塗り＋マスク方式

Source: [How to Add Fog in Photoshop](https://www.youtube.com/watch?v=DXP-fEOwoZY)

## 概要
べた塗り調整レイヤー（Solid Color）とレイヤーマスクを組み合わせ、非破壊でフォグを描画する手法。雲フィルターよりもフォグの配置・形状・密度を自由にコントロールできる。

## 手順

### Step 1: フォグの色を決める
- **スポイトツール（Eyedropper / I）** で画像内からフォグに使いたい色をサンプリング
- または直接カラーピッカーで暖色系のフォグ色を指定

### Step 2: べた塗りレイヤーの作成
- レイヤーパネル下部の半月アイコン → **「べた塗り...」（Solid Color...）**
- サンプリングした色で OK

### Step 3: グループ化＋黒マスク
1. べた塗りレイヤーを選択 → レイヤーパネル下部の **フォルダアイコン** でグループ化
2. **Option (Mac) / Alt (Win) + レイヤーマスク追加アイコン** をクリック
   → 黒マスクが作成され、フォグは一時的に非表示になる

### Step 4: グラデーションでフォグのベースを作る
- グループの黒マスクを選択
- **グラデーションツール（G）** → プリセット「描画色から透明（Foreground to Transparent）」
- 描画色を **白** にする（D → X で切替）
- 画像の下部から上部へドラッグ → ソフトな霞のベースができる

### Step 5: べた塗りマスクを反転
- べた塗りレイヤーのマスクサムネイルを選択
- **Cmd+I（Mac）/ Ctrl+I（Win）** でマスクを反転 → べた塗りが非表示に

### Step 6: ブラシでフォグを描画
- **ブラシツール（B）** → フォグ/スモーク系ブラシを選択
  - 動画では「Dirt_and_smoke」カスタムブラシの「D_04」を使用
  - Photoshop標準のソフト円ブラシでも代用可
- **流量（Flow）: 15%** 程度に設定
- べた塗りレイヤーのマスク上に **白** でフォグを描画
- ソフト円ブラシで光が当たる部分を追加で明るくする

### Step 7: 仕上げ — ぼかし（移動）
- べた塗りレイヤーのマスクを選択した状態で
- **フィルター > ぼかし > ぼかし（移動）（Filter > Blur > Motion Blur）**
  - 距離: **17px** 程度
  - 角度: フォグの流れに合わせて調整
- フォグに風の流れ感が加わりリアルになる

## 調整のコツ
- べた塗りレイヤーのカラーボックスをダブルクリック → いつでも色を変更可能
- マスクを Cmd+T で自由変形 → フォグの位置・スケールを調整
- グループマスクのグラデーションで全体の霞の濃度をコントロール

## 雲フィルター方式との使い分け
| | べた塗り＋マスク方式 | 雲フィルター方式 |
|---|---|---|
| 配置の自由度 | 高い（ブラシで自在に描画） | 低い（ランダム生成） |
| 非破壊性 | 色・形状とも後から変更可 | 再生成が必要 |
| 適した用途 | 局所的なフォグ、特定位置の雲 | 全面的な星雲・大気感 |
