# 放射状の線（サンバースト／スターバースト）の作り方

## 概要
回転ツールのコピー機能と Command+D（変形の繰り返し）を使って、放射状に広がる線を効率的に作成するテクニック。

## 手順

### 1. ベースの線を作る
1. **ペンツール（P）**で垂直な線を作成（Shift押しながら）
2. 塗り: なし、線色: 黒
3. **Command+C → Command+F** で前面にペースト
4. コピーした線の色を変えて視認性を確保（マゼンタ等）
5. **ダイレクト選択ツール（A）**で片方のアンカーを動かし短くする
6. Shift+Option ドラッグで複製を作り、等間隔に3本程度並べる

### 2. パスファインダーで分割
1. 全オブジェクト選択
2. **オブジェクト（Object）→ パス（Path）→ パスのアウトライン（Outline Stroke）**
3. **パスファインダー（Pathfinder）**パネル →「**分割（Divide）**」
4. **Shift+Command+G** でグループ解除
5. 不要な部分（カット用のマゼンタ部分）を選択して Delete
6. 残った破線パーツを **Command+G** でグループ化

### 3. 回転コピーで放射状に展開
1. グループを選択した状態で **回転ツール** をダブルクリック
2. 角度に **3の倍数**（9度 など）を入力 → 「**コピー**」をクリック
3. **Command+D** を繰り返し押して360度分を生成

### 4. 動きを付ける（オプション）
- 一部の放射線を90度回転させてカット位置をずらす
- ランダムに破線の一部を削除してスパークル感を演出

### 5. 中心を白く抜く
1. **楕円形ツール（L）**でShift押しながら正円を作成（白塗り、線なし）
2. 放射線と正円を選択 → **整列（Align）**パネルで中央揃え
3. **パスファインダー →「分割」**
4. グループ解除 → 黒い部分を **選択（Select）→ 共通（Same）→ カラー（塗り）（Fill Color）** で一括選択
5. Command+G でグループ化 → Command+3 で非表示
6. Command+A → Delete で白い不要部分を削除
7. Option+Command+3 で黒い部分を再表示

### 6. 仕上げ
- **効果（Effect）→ スタイライズ（Stylize）→ 角を丸くする（Round Corners）** で端を柔らかく
- **グラデーション（Gradient）**パネルで放射状グラデーションを適用
- **透明（Transparency）**パネルで描画モードを「**スクリーン（Screen）**」に変更（RGBモード限定）

## ポイント
- 回転角度は **360の約数** or **3の倍数** が均等に揃う（9度 = 40本、6度 = 60本、etc.）
- パスファインダーの「分割」で破線を作るのが効率的（手動で描くより正確）
- スクリーン描画モードは背景と溶け合う光の表現に有効（要RGBカラーモード）
