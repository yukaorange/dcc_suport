# 2Dアニメ風エフェクトの造形原則（炎・流星・トレイル）

アニメ/ゲームの2D FXで共有されている「手描きに見えるための設計ルール」。
ツールを問わず適用できる。Illustratorのベクター造形にもそのまま使える。

## 1. ジェスチャーライン（S字の流れ）
- まず一本のS字（S-swoop）で全体の流れと風向きを決める。
- 炎は「太い根元 → 細く尖る先端」のテーパー。流星では頭部が根元、尾が先端。
- 直線ではなく、付け根でわずかにたわむ弧にすると風を受けた感じが出る。

## 2. C字カット（負の空間 / 抜き）
- 輪郭をC字の曲線で「削り取る」ことでベタの塊感（toothpaste blob）を壊す。
- C字の端が本体と交わる所に「フック（かぎ状の鋭い先端）」を作り、丸い曲線と尖りのコントラストを出す。
- 内側にも C字・フック・スウープを足して面の前後関係（擬似的な立体感）を作る。やりすぎ注意、数本で十分。

## 3. BMS（Big / Medium / Small）
- 正の面だけでなく、穴（負の面）にも大・中・小の変化をつける。
- 同じ大きさ・同じ間隔で並べない。対称を避ける。
- 密集 → 疎のグラデーション配置でスピード感が出る。

## 4. シェイプランゲージの3段階
- **Curved**（丸い曲線）: 柔らかい・魔法的
- **Curve-linear**（曲線と直線の混在）: アニメの標準。リファレンスの流星はここ
- **Linear**（直線的）: 鋭い・攻撃的
- 同じ後処理（発光）をかけても、この造形の違いだけで印象が変わる。

## 5. Thick & Thin / 二次形状
- 主形状（プライマリ）を、太さの異なる二次形状（セカンダリ）で割る。
- 線幅・太さ・深さ・大きさのどれかに必ず変化を入れる。

## 6. 不完全なエッジ
- 曲線を正確に引きすぎない。所々に揺らぎと「呼吸する余白」を残す。
- ベクターでもアンカーを1〜2px意図的にずらすと手描き感が出る。

## 7. ワークフロー（ブロックアウト → 簡略化）
- まず大胆に（bold に）ブロックアウトし、最後に削って簡略化する。
- モーションパス（流れの線）と目標スタイルを先に決めてからディテールに入る。

## 流星への適用メモ
- 頭部 = 根元（太い）。尾 = テーパーして画面外へ。
- 頭部内部の穴は BMS で配置し、流れに沿って楕円に歪ませる。
- 後方へ流れるベロは「C字カット + フック」の組み合わせで作る。
