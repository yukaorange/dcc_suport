# 雲・フォグのエッジ発光表現

## 概要
雲やフォグのエッジ付近を発光させ、ブルー・パープル系の美しい色味を加える技法。
宇宙背景やファンタジー系のシーンで、単調なフォグに光源との関係性と色彩の美しさを与える。

## 手法A: 覆い焼きカラー（Linear Dodge/Add）＋ソフトブラシ

最も直接的な方法。フォグレイヤーの上に発光色を重ねる。

1. フォグレイヤーの上に**新規レイヤー**を作成
2. 描画モードを**「覆い焼きカラー（Linear Dodge (Add)）」**に設定
3. **ソフトブラシ（硬さ0%）**で以下の色をフォグのエッジ付近に描画：
   - 赤紫系: `#eb08b4`
   - 青紫系: `#8309a9`
   - 淡いブルー: `#4a6bff`
4. 不透明度で発光の強さを調整

**ポイント**: 覆い焼きカラーは暗い背景の中で光が際立つ効果を生む。複数の色を重ねると豊かな発光になる。

## 手法B: グラデーションマップ＋レイヤーマスク

雲模様の明暗構造を活かして自動的に色を割り当てる方法。

1. フォグレイヤーの上に**調整レイヤー > グラデーションマップ（Gradient Map）**を作成
2. クリッピングマスク（Cmd+Option+G / Ctrl+Alt+G）で対象フォグに限定
3. グラデーション設定：
   - 左端（暗い部分）: ダークブルー/パープル
   - 右端（明るい部分）: 明るいブルー〜ライトパープル
4. 描画モードを**「比較（明）（Lighter Color）」**に設定
5. 不透明度を50%程度に調整
6. 「ディザ（Dither）」にチェックを入れるとバンディングが軽減

**ポイント**: 雲の明るい部分＝エッジ付近に明るい色が自動的に乗る。非破壊で調整しやすい。

## 手法C: 色相・彩度調整レイヤー＋マスクペイント

部分的に色味を変える精密な方法。

1. フォグレイヤーの上に**調整レイヤー > 色相・彩度（Hue/Saturation）**を作成
2. クリッピングマスクで対象フォグに限定
3. 色相をパープル〜ブルー方向にシフト、彩度を上げる
4. レイヤーマスクを**Cmd+I（反転）で黒に**
5. **ブラシツール（白）**でエッジ発光させたい部分だけマスクを塗る

**ポイント**: 発光の位置と強さを完全にコントロールできる。光源の方向を意識して片側だけ塗ると自然。

## 手法D: 覆い焼きカラー＋ブラシ描画＋スマッジ（ネビュラ技法）

動画 [Painting a Nebula - Tim Barton](https://www.youtube.com/watch?v=hPCkNChOpjI) より抽出。
ネビュラ（星雲）の発光エッジを描く技法。雲・フォグのリム発光にもそのまま適用できる。

### 手順
1. 新規レイヤー → 描画モード**「覆い焼きカラー（Linear Dodge (Add)）」**
2. ブラシ設定をカスタム：
   - **カラーダイナミクス（Color Dynamics）**: 色相ジッター4%、彩度ジッター4%、明るさジッター4%
   - **転送（Transfer）**: 流量ジッター42%、コントロール「筆圧（Pen Pressure）」
   - **流量（Flow）**: 30%、**不透明度（Opacity）**: 100%
3. **暗めの色**（ダークブルー `#2a3a6a`、ダークパープル `#4a2a5a` など）でエッジに沿って描画
   - 覆い焼きカラーが色を明るくするので、暗めの色を使わないと飛びすぎる
4. **スマッジツール（Smudge Tool / R）**に切り替え、強さ30%
   - 描いた光を**雲の内側に向かって引き延ばす** → ガスっぽい流動的な形になる
5. 手順3-4を**何度も繰り返す** — 一発で仕上げず、薄く重ねて複雑さを出す

### ポイント
- **暗めの色を選ぶ**: 覆い焼きカラーが加算で明るくするため、明るい色だと光が飛ぶ
- **スマッジで内側に引き延ばす**: エッジから内側へのハーフトーン（回り込み）が自然にできる
- **カラーダイナミクスで色揺らぎ**: 色相・彩度・明るさが微妙に変化し、単調にならない
- **複数レイヤーを重ねる**: 一度のパスで完璧にせず、何度もレイヤーを重ねて複雑さを構築

## 組み合わせの推奨

実際の制作では、手法Aで大まかな発光色を置き、手法Dでエッジの描き込みとスマッジを行い、手法Cで部分的な調整を加えるのが効果的。

## リムライト描画の4原則

動画 [Watch THIS before you paint RIM LIGHT!](https://www.youtube.com/watch?v=NbI-PIkIYZE) より抽出。雲・フォグのエッジ発光にもそのまま適用できる。

### 1. 非均一性（Non-uniform）
リムライトは形状の凹凸に応じて太さ・明るさが変化する。均一な線にしない。
雲の場合：もこもこした輪郭の突起部は明るく太く、谷部分は細く暗くなる。

### 2. フォームに沿って回り込む（Wraps over the form）
光はエッジだけでなく、表面を包み込むように広がる。
雲の場合：エッジのすぐ内側にもハーフトーンとして光が入り込む領域がある。

### 3. アウトラインではない（Not like an outline）
マンガ的な均一ラインではなく、遮蔽や反射の弱まりで途切れ・内側への入り込み・薄れが生じる。
雲の場合：雲塊の重なりで手前の雲が奥の光を部分的に遮り、リムが途切れる。

### 4. 素材による色・バリューの変化
同じ光源でも、当たる素材（密度の高い雲 vs 薄いフォグ）で色とバリューが変わる。
雲の場合：薄い部分はより透過して青白く、厚い部分はパープル〜ラベンダー寄りに。
