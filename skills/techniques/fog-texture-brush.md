# フォグ・霧のテクスチャ表現（ブラシ手法）

## 概要
クラウドブラシを使って写真やイラストにリアルな霧・フォグのテクスチャを追加する手法。

## 基本手順

### 方法A: 新規レイヤーに直接描画
1. 新規レイヤーを作成し「Fog Texture」等の名前をつける
2. ブラシツール（B）でクラウド系ブラシを選択
3. 前景色を白に設定
4. ブラシ設定（F5 / Window > Brush Settings）で以下を調整：
   - **シェイプ（Shape Dynamics）> 角度のジッター（Angle Jitter）: 60%** — 塗布時にランダム回転、パターン繰り返し防止
5. オプションバーで Flow 50〜80%、Opacity は必要に応じて20〜100%
6. 霧を追加したい部分にペイント
7. レイヤーの不透明度で全体の濃さを微調整

### 方法B: べた塗りレイヤー + マスク
1. べた塗り調整レイヤーを追加（フォグの色を指定）
2. マスクを Cmd+I で黒に反転（全体を隠す）
3. ブラシで白を塗った部分だけフォグが表示される
4. マスクへの描画なので、色の変更が後から容易

## ブラシ選びのコツ
- 名前に「Cloud」「Smoke」「Fog」がなくても、**エッジが不規則でモコモコした形状**ならフォグに使える
- 「Spatter」「Wet」系のブラシも候補になる
- ブラシプリセットピッカーの表示を**大きなサムネイル**にして形で判断する

## 表現技法ポイント
- **角度のジッター（Angle Jitter）**: 同じブラシパターンの繰り返しを防ぎ、有機的な質感を生む
- **複数レイヤー分割**: 奥・中・手前のフォグを別レイヤーで管理し、不透明度や色を独立調整
- **コントラスト低減との併用**: Curves調整レイヤーでブラックポイントを上げると、霧による視界の曖昧さを再現できる（写真合成向け）
